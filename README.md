# 🐾 Pawzy - Red Social para Mascotas
Pawzy es una red social desarrollada con Spring Boot y Thymeleaf que permite a los usuarios compartir fotos de sus mascotas, comentar publicaciones y dar "me gusta".
¡Una comunidad pensada para los amantes de los animales!

#🌐 Tecnologías utilizadas
Backend : Spring Boot, Spring MVC, Spring Security, JPA/Hibernate
Interfaz : Thymeleaf, Bootstrap, CSS
Base de datos : MySQL
Almacenamiento de Imágenes : Sistema de archivos locales
#📂 Estructura del Proyecto
es.fempa.acd.redsocialpawzy ├── config # Configuraciones del proyecto ├── driver # Controladores ├── dto # Objetos de transferencia de datos ├── model # Modelos de datos ├── repository # Acceso a datos ├── service # Lógica de negocio └── RedSocialPawzyApplication # Clase principal

#⚙️ Instalación y configuración
📄 Prerrequisitos
Java 17 o superior
Maven 3+
MySQL 8+
IDE como IntelliJ IDEA, VS Code o Eclipse
