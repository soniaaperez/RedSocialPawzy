# 🐾 Pawzy - Red Social para Mascotas

**Pawzy** es una red social desarrollada con **Spring Boot** y **Thymeleaf** que permite a los usuarios compartir fotos de sus mascotas, comentar publicaciones y dar "me gusta".  
¡Una comunidad pensada para los amantes de los animales!

---

## 🌐 Tecnologías utilizadas

- **Backend**: Spring Boot, Spring MVC, Spring Security, JPA/Hibernate  
- **Frontend**: Thymeleaf, Bootstrap, CSS  
- **Base de Datos**: MySQL  
- **Almacenamiento de Imágenes**: Sistema de archivos local

---

## 📂 Estructura del Proyecto

es.fempa.acd.redsocialpawzy
├── config # Configuraciones del proyecto
├── controller # Controladores
├── dto # Objetos de transferencia de datos
├── model # Modelos de datos
├── repository # Acceso a datos
├── service # Lógica de negocio
└── RedSocialPawzyApplication # Clase principal
